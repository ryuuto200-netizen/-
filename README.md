# SKYLINE ATLAS — 東京スカイツリーから見渡す東京

天望デッキ約350mを基準に、360°の方位・各地への直線距離を調べ、南西方面の実写資料を閲覧できる静的サイトです。

## 使い方

`index.html` を静的 Web サーバーで開きます。依存ライブラリのビルドや API キーは不要です。

```sh
python3 -m http.server 8080
```

ブラウザーで `http://localhost:8080/` を開いてください。左右ドラッグ、方位角スライダー、東西南北ボタン、ランドマーク検索、写真カードが使えます。URL の `bearing`、`spot`、`mode` で表示を共有できます。

地図は MapLibre GL JS と OpenFreeMap のオンライン配信を使用します。写真と地図の表示にはネットワーク接続が必要です。方位と距離の計算はブラウザー内で動作します。

## 表現の範囲

- 360°を連続して動かせるのは**方位と地図**です。写真は南西方向の個別の過去資料で、全方角を連続撮影したパノラマではありません。
- 地図上の建物は OpenStreetMap の記録に依存します。写真の撮影時刻、現在の天候、遠景の可視性は同期していません。
- 地図の建物高さが登録されていれば拡大時（ズーム15以上）に押し出し表示します。全ての建物を高精度な形状や高さで再現するものではありません。
- 写真の作者・ライセンスとデータの出典は [CREDITS.md](./CREDITS.md) に記載しています。
